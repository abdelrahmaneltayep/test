أولًا: السؤال الأول - اختاري الإجابة الصحيحة من بين البدائل:[٤ درجات - درجة لكل نقطة]

  1. ١. شبكة فرعية توضع فيها الخوادم المواجهة للجمهور (مثل خادم الويب) لعزلها عن الشبكة الداخلية هي:
    (أ) الشبكة الافتراضية الخاصة (VPN)(ب) المنطقة المعزولة (DMZ)(ج) جدار الحماية (Firewall)(د) نهج انعدام الثقة (Zero Trust)
  2. ٢. الترتيب الصحيح لأول ثلاث مراحل في الاستجابة للحوادث هو:
    (أ) التحضير ← الاكتشاف ← الاحتواء(ب) الاكتشاف ← التحضير ← الاستعادة(ج) الاحتواء ← الاستئصال ← التحضير(د) التحضير ← الاستعادة ← الاكتشاف
  3. ٣. رمز حالة HTTP الذي يعني أن المورد المطلوب غير موجود بهذا العنوان هو:
    (أ) 200(ب) 404(ج) 500(د) 300
  4. ٤. الوسيلة المناسبة لإيصال المعلومات مباشرة لأشخاص محددين هي:
    (أ) التلفزيون(ب) البريد الإلكتروني(ج) الصحيفة(د) الراديو

  1. ١. الشبكة الافتراضية الخاصة (VPN) تنشئ اتصالًا خاصًا مشفرًا عبر شبكة عامة مثل الإنترنت.(     )
  2. ٢. مرحلة الاستعادة يجب أن تسبق مرحلة الاستئصال في الاستجابة للحوادث.(     )
  3. ٣. الواجهة الأمامية لتطبيق الويب تعمل على الخادم.(     )
  4. ٤. تُستخدم طريقة POST عادةً لإرسال بيانات ليعالجها الخادم مثل معلومات تسجيل الدخول.(     )
  5. ٥. لغة CSS تحدد بنية (هيكل) صفحة الويب.(     )
  6. ٦. الراديو ينقل المعلومات من خلال الصوت.(     )

ثالثًا: السؤال الثالث - الأسئلة المقالية (أجيبي في المساحة المخصصة):[٤.٥ درجات - ١.٥ درجة لكل نقطة]

  1. ١. قارني بين الدفاع متعدد الطبقات (Defense in Depth) ونهج انعدام الثقة (Zero Trust).
  2. ٢. اذكري الطبقات الثلاث لتطبيق الويب مع دور ومكان كل منها.
  3. ٣. اذكري ثلاث نقاط قوة وقيدين للمواقع الإلكترونية.

رابعًا: السؤال الرابع - دراسة حالة ومسائل:[٣ درجات]

دراسة حالة: لشركة موقع إلكتروني عام، وموظفون يعملون عن بُعد، وقاعدة بيانات للعملاء.

  1. أ) حدّدي طبقة الحماية المناسبة لكل من: الموقع العام، والموظفين عن بُعد، وقاعدة البيانات الداخلية. [١.٥ درجة]
  2. ب) يطلب موقع الشركة بيانات منتج عبر API ويستقبل: {"product": "Laptop", "price": 15000, "stock": "yes"}. ما صيغة البيانات؟ استخرجي المفاتيح، وحددي القيمة الرقمية. [١.٥ درجة]
