أولًا: السؤال الأول - اختاري الإجابة الصحيحة من بين البدائل:[٤ درجات - درجة لكل نقطة]

  1. ١. أصغر وحدة تتكون منها الصورة الرقمية هي:
    (أ) البكسل (Pixel)(ب) البت (bit)(ج) dpi(د) التدرج
  2. ٢. نظام ينقل البيانات بين الإنسان والأجهزة مثل الإدخال بالصوت والشاشة اللمس يسمى:
    (أ) تجربة المستخدم (UX)(ب) واجهة المستخدم (UI)(ج) التصميم الشامل(د) الدلالة (Signifier)
  3. ٣. الواجهة التي تنقل الفيديو والصوت والبيانات عبر كابل واحد هي:
    (أ) USB(ب) HDMI(ج) Ethernet(د) SSD
  4. ٤. المكمل للعشرة للعدد 47 هو:
    (أ) 52(ب) 53(ج) 63(د) 43

ثانيًا: السؤال الثاني - ضعي علامة (✓) أو علامة (✗) أمام العبارات:[٣.٥ درجات - نصف درجة لكل نقطة]

  1. ١. المكمل للآحاد للعدد الثنائي 1100 هو 0011.(     )
  2. ٢. المكمل الثنائي (للاثنين) = المكمل للآحاد − 1.(     )
  3. ٣. الطابعات الملونة تستخدم مزج الألوان الطرحي.(     )
  4. ٤. الأيقونة (Icon) تمثل محتوى البرنامج على الكمبيوتر أو الهاتف بصور أو رسوم توضيحية.(     )
  5. ٥. ذاكرة RAM مثال على ذاكرة التخزين الثانوية.(     )
  6. ٦. برنامج تشغيل الجهاز (Device driver) يتحكم في الاتصال بين الجهاز المتصل والبرمجيات.(     )
  7. ٧. نظام التشغيل مسؤول عن الوظائف الأساسية للكمبيوتر مثل إدارة المهام والذاكرة والملفات.(     )

ثالثًا: السؤال الثالث - الأسئلة المقالية (أجيبي في المساحة المخصصة):[٤.٥ درجات - ١.٥ درجة لكل نقطة]

  1. ١. فرّقي بين برامج النظام وبرامج التطبيقات مع ذكر مثالين لكل منهما.
  2. ٢. اذكري خطوات رقمنة الصورة الثلاث بالترتيب مع شرح موجز لكل خطوة.
  3. ٣. اذكري تصنيفات مبدأ LATCH الخمسة مع مثال لثلاثة منها.
