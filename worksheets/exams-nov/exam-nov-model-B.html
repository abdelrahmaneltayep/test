أولًا: السؤال الأول - اختاري الإجابة الصحيحة من بين البدائل:[٤ درجات - درجة لكل نقطة]

  1. ١. برنامج يجعل البيانات غير قابلة للوصول ويطالب بفدية لاستعادتها هو:
    (أ) Spyware(ب) Keylogger(ج) Ransomware(د) Adware
  2. ٢. 1 GB يساوي:
    (أ) 1000 MB(ب) 1024 MB(ج) 1024 KB(د) 8 MB
  3. ٣. معيار ترميز يجمع حروف كل لغات العالم في نظام رموز واحد هو:
    (أ) ASCII(ب) Unicode(ج) النظام الثنائي(د) الخط (Font)
  4. ٤. الواجهة الأكثر استخدامًا لتوصيل الأجهزة الطرفية بالكمبيوتر هي:
    (أ) HDMI(ب) USB(ج) Ethernet(د) SSD

ثانيًا: السؤال الثاني - ضعي علامة (✓) أو علامة (✗) أمام العبارات:[٣.٥ درجات - نصف درجة لكل نقطة]

  1. ١. كلمة المرور لمرة واحدة (OTP) تمنع الوصول غير المصرح به باستخدام كلمة مرور مسربة.(     )
  2. ٢. رقم جواز السفر ورقم البطاقة القومي ليسا بيانات شخصية لأنهما مجرد أرقام.(     )
  3. ٣. 3 bit يمكنها تمثيل 6 احتمالات مختلفة.(     )
  4. ٤. أكبر عدد يُكتب بخانتين في النظام السادس عشر هو (FF)₁₆ ويساوي 255.(     )
  5. ٥. الرسم التصويري (Pictogram) رمز يوصّل البيانات دون استخدام كلمات، مثل علامة مخرج الطوارئ.(     )
  6. ٦. عند مزج ألوان الضوء الأساسية يزداد السطوع ويقترب اللون من الأسود.(     )
  7. ٧. ناتج جمع 1₂ + 1₂ في النظام الثنائي هو 10₂.(     )

ثالثًا: السؤال الثالث - الأسئلة المقالية (أجيبي في المساحة المخصصة):[٤.٥ درجات - ١.٥ درجة لكل نقطة]

  1. ١. اذكري أربعة إرشادات لإنشاء كلمة مرور قوية، ثم عرّفي كلمة المرور لمرة واحدة (OTP).
  2. ٢. حوّلي العدد (B7)₁₆ إلى النظام الثنائي، ثم إلى النظام العشري، مع توضيح الخطوات.
  3. ٣. اذكري خطوات رقمنة الصورة الثلاث بالترتيب مع شرح موجز لكل خطوة.

  1. أ) باستخدام جدول ASCII، اكتبي رموز كلمة "CAT" بالنظام السادس عشر، واحسبي حجم بياناتها بالبت. [١.٥ درجة]
  2. ب) احسبي 1011₂ − 0011₂ باستخدام المكمل الثنائي، مع توضيح الخطوات. [١.٥ درجة]
