مقدمة

الفكرة: "البرمجة" تعني إعطاء التعليمات للحاسوب. نكتب في المحرر، وتظهر النتيجة في وحدة التحكم.

أول برنامج: console.log

console.log("Hello");
Console ▸
Hello
console.log("Good morning");
Console ▸
Good morning
console.log("Good evening");
Console ▸
Good evening

اكتشف الخطأ وصحّحه

console.log(see you tomorrow);
Console ▸
Uncaught SyntaxError: missing ) after argument list
console.log("Good luck")
Console ▸
Good luck

التعليق //

بدون // تُعامَل الملاحظة ككود:

When executed, the text is output to the console.
console.log("Hello");
Console ▸
Uncaught SyntaxError: Unexpected identifier 'executed'
//When executed, the text is output to the console.
console.log("Hello");
Console ▸
Hello

التعليق خارج البرنامج (تعطيل سطر)

//Greetings for the day.
console.log("Good morning");
console.log("Hello");
console.log("Good evening");

Hello
Good evening
console.log("Eggs")
//console.log("Apple");
console.log("Milk");
Console ▸
Eggs
Milk
console.log("Lion");
//console.log("Fish");
console.log("Elephant");
console.log("Giraffe");
Console ▸
Lion
Elephant

سؤال تفاعلي: كم عدد لغات البرمجة في العالم؟ 3 / 10 / أكثر من 100 ← أكثر من 100 نوع

النقاط الأساسية

  • تُكتب البرامج بلغات برمجة، وليس بأحرف عادية.
  • ترك ملاحظة في البرنامج يُسمى "تعليق"، ويُسبق بـ // في بداية كل سطر.
  • يمكنك منع تنفيذ البرنامج مؤقتًا بوضع // في بدايته.

الحسابات والنصوص

الفكرة: للحساب نحذف علامتي الاقتباس، ونربط النص بالصيغة الحسابية بـ + مع وضع الصيغة بين أقواس.

مع " " وبدونها

console.log("1+1");
Console ▸
1+1
console.log(1+1);
Console ▸

Console ▸
5000

المتغيرات

الفكرة: let تُنشئ متغيّرًا (إعلان)، و = تضع فيه قيمة (إسناد)، وتغييرها يُسمى إعادة الإسناد.

let fish;
fish = 0;
fish = fish + 3;
fish = fish + 7;
console.log(fish);
Console ▸
10
let fish;
fish = 0;
fish = fish + 8;
fish = fish + 12;
console.log(fish);
Console ▸
20
let apple;
apple = 0;
apple = apple + 5;
apple = apple + 8;
console.log(apple);
Console ▸
13
console.log("fish");
Console ▸
fish
let allowance;
allowance = 700;
allowance = allowance + 1500;
console.log(allowance);
Console ▸
2200
ملاحظةصياغة المنصة «أسند 1500 إلى allowance» تقصد الإضافة على 700، والمنصة تقبل الناتج 2200. لو كُتبت allowance = 1500; تكون النتيجة 1500.

النقاط الأساسية

  • إعلان: let variable; — إسناد: variable = value; — عرض: console.log(variable);
  • علامات الاقتباس غير ضرورية عند عرض القيم.

جملة if

الفكرة: if (شرط) { معالجة } تنفّذ المعالجة فقط عند تحقق الشرط، والمقارنة تكون بـ ==.

الإعلان والإسناد في سطر واحد

let fish = 0;
console.log(fish);
Console ▸
0
let fish;
fish= 0;
console.log(fish);
Console ▸
0
let fish = 0;
fish = fish + 5;
console.log(fish);
Console ▸
5
let apple = 0;
apple = apple + 10;
console.log(apple);
Console ▸
10

جملة if

let science = 100;
if (science == 100){console.log("Increased allowance!");}
Console ▸
Increased allowance!
let science = 80;
if (science == 100){console.log("Increased allowance!");}

النتيجة: لا يظهر شيء في وحدة التحكم.

let math= 100;
if (math == 100){console.log("Get a reward");}
Console ▸
Get a reward

الشرط ينتج true أو false

let science = 100;
console.log(science == 100);
Console ▸
true
let science = 80;
console.log(science == 100);
Console ▸
false

سؤال تفاعلي: هل سيُخرج البرنامج التالي "true" أم "false"؟

let math = 80;
console.log(math == 80);
Console ▸
true

النقاط الأساسية

  • let variable = value; للإعلان والإسناد في سطر واحد.
  • if (شرط) { معالجة } — والمعالجة بين أقواس معقوفة { }.
  • للمقارنة نستخدم == (علامتي مساواة).
