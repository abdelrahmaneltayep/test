مقدمة

الفكرة الأساسية

تعريف الطالب بمعنى البرمجة وفائدتها في حياتنا، ثم كتابة أول برنامج JavaScript لعرض نص في وحدة التحكم باستخدام console.log، وتعلّم التعليقات.

الدروس

الدرس 1 — ما هي البرمجة؟ (١)

قصة تمهيدية بين الشخصيات (كودي وريكي): البرمجة تتيح صنع ألعاب ومواقع وتطبيقات. لا يوجد كود في هذا الدرس.

النقطة الأساسية: البرمجة تتيح لك إنشاء الألعاب والمواقع والتطبيقات وغيرها.

الدرس 2 — ما هي البرمجة؟ (٢)

  • البرمجة = إعطاء تعليمات للحاسوب، ومجموعة التعليمات تُسمى "برنامج".
  • البرامج تشغّل الحواسيب والأجهزة المنزلية والسيارات وغيرها حولنا.
  • يوجد أكثر من 100 لغة برمجة؛ في هذا الكورس نتعلم ثلاثًا: HTML و CSS و JavaScript.
  • سؤال تفاعلي داخل الدرس: كم عدد لغات البرمجة في العالم؟ → أكثر من 100 نوع

الدرس 3 — كيفية استخدام المحرر

المحرر (الشاشة السوداء) هو مكان كتابة البرنامج. الأحرف العادية وحدها لا يفهمها الحاسوب.

المتغيرات

الفكرة الأساسية

المتغيّر "صندوق" نضع فيه قيمة ونغيّرها، نعلنه بـ let ونُسند له القيم بـ = ونعرض محتواه بـ console.log بدون علامات اقتباس.

الدروس

الدرس 1 — الإعلانات والإسنادات

مثال الصيد: الدلو فارغ (0)، ثم 3 أسماك صباحًا، ثم 7 بعد الظهر.

let fish;
fish = 0;
fish = fish + 3;
fish = fish + 7;
console.log(fish);
Console ▸
10
  • let fish; = إعلان متغيّر جديد اسمه fish.
  • fish = 0; = إسناد قيمة له.
  • fish = fish + 3; = إعادة إسناد.
  • اسم المتغيّر تختاره أنت بما يعبّر عن محتواه.

الفرق بين المتغيّر والنص:

console.log("fish");
Console ▸
fish

← النص نفسه، وليس قيمة المتغيّر.

الدرس 2 — تدريب على المتغيّرات

fish = fish + 12;

Console ▸

let apple;
apple = 0;
apple = apple + 5;
apple = apple + 8;
console.log(apple);
Console ▸
13

تمرين المصروف — القيمة الابتدائية ليست بالضرورة 0:

let allowance;
allowance = 700;
allowance = allowance + 1500;
console.log(allowance);
Console ▸
2200
ملاحظةملاحظة للمعلّم: نص التمرين في المنصة مختصر ("أسند 1500 إلى allowance")، لكن سياق القصة هو إضافة المصروف إلى الـ 700 الموجودة أصلًا. لو أُسندت 1500 مباشرة (allowance = 1500;) يصبح الناتج 1500. هذه فرصة ممتازة لتنبيه الطلاب للفرق بين الإسناد وإعادة الإسناد بالإضافة.

جملة if

الفكرة الأساسية

اختصار كتابة المتغيّرات في سطر واحد، ثم تعلّم التفرّع الشرطي if (شرط) { معالجة }، وفهم أن الشرط نفسه ينتج true أو false.

الدروس

الدرس 1 — كيفية كتابة المتغيّرات

الطريقة السابقة (سطران):

let fish;
fish= 0;
console.log(fish);
Console ▸
0

الاختصار (سطر واحد):

let fish =0;
console.log(fish);
Console ▸
0

مع إعادة الإسناد:

let fish = 0;
fish = fish + 5;
console.log(fish);
Console ▸
5

تمرين:

let apple = 0;
apple = apple + 10;
console.log(apple);
Console ▸
10

القاعدة: الاختصار let variable = value; يصلح للإسناد الأول فقط؛ إعادة الإسناد تُكتب بالطريقة المعتادة بدون let.

الدرس 2 — جملة if

التفرّع الشرطي يعني: "إذا تحقق كذا، فافعل كذا". مثال القصة: إذا حصل ريكي على 100 في العلوم يحصل على مصروف إضافي.

let science = 100;
if (science == 100){console.log("Increased allowance!");}
Console ▸
Increased allowance!

الدرس 3 — تدريب على if statement

  • جزء if (...) يُسمى العبارة الشرطية (conditional expression).
  • جزء { ... } يُسمى المعالجة (processing)، ويُحاط بأقواس معقوفة { } تُسمى curly brackets.
  • للمقارنة نستخدم == (علامتا مساواة)، وللإسناد = (علامة واحدة). الفرق جوهري.
let science = 100;
if (science == 100){console.log("Increased allowance!");}
Console ▸
Increased allowance!

تمرين أخير:

let math= 100;
if (math == 100){console.log("Get a reward");}
Console ▸

الدرس 4 — كيفية عمل if statements

العبارة الشرطية وحدها تنتج قيمة، ويمكن طباعتها مباشرة. (تم تشغيل هذين المثالين فعليًا في محرر المنصة والتحقق من الناتج)

let science = 100;
console.log(science == 100);
Console ▸
true
let science = 80;
console.log(science == 100);
Console ▸
false

الخلاصة: إذا تحقق الشرط فالنتيجة true، وإذا لم يتحقق فالنتيجة false. وجملة if تنفّذ المعالجة فقط عندما تكون النتيجة true.

سؤال تفاعلي في نهاية الدرس:

let math = 80;
console.log(math == 80);

الإجابة الصحيحة: true

أهم 3 أخطاء شائعة

  1. استخدام = بدل == داخل الشرط (إسناد بدل مقارنة).
  2. نسيان الأقواس المعقوفة { } حول جزء المعالجة.
  3. استخدام الاختصار let مع إعادة الإسناد (كتابة let مرة ثانية لنفس المتغيّر).
