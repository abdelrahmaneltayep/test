مقدمة

التصنيف: متوسط (6 دروس، معظمها تمهيدي + أمر برمجي واحد جديد + التعليقات)

1. الفكرة الأساسية

البرمجة هي إعطاء تعليمات للحاسوب بلغة يفهمها. في هذا الفصل نكتب أول برنامج JavaScript ونُخرج نصًا إلى وحدة التحكم، ونتعلّم كيف نترك ملاحظات داخل البرنامج.

2. المفاهيم الجديدة

أ) المحرر ووحدة التحكم

الشاشة التي نكتب فيها البرنامج اسمها المحرر، والشاشة التي تظهر فيها النتيجة اسمها وحدة التحكم. إظهار شيء في وحدة التحكم يُسمى "إخراج".

ب) الأمر console.log

console.log("Hello");
Console ▸
Hello

النص يوضع بين علامتي اقتباس مزدوجتين " ". الفاصلة المنقوطة ; في النهاية تدل على انتهاء الجملة؛ البرنامج يعمل بدونها لكن القاعدة أن نكتبها دائمًا.

ج) الخطأ عند نسيان علامات الاقتباس

console.log(see you tomorrow);
Console ▸
Uncaught SyntaxError: missing ) after argument list

د) التعليق //

السطر الذي يبدأ بـ // لا يُنفّذ، ويُستخدم لترك ملاحظة:

//When executed, the text is output to the console.
console.log("Hello");
Console ▸
Hello

← فقط

هـ) التعليق خارج البرنامج

إذا وضعنا // أمام سطر برمجي فعّال، نوقف تنفيذه مؤقتًا:

console.log("Eggs")
//console.log("Apple");
console.log("Milk");
Console ▸
Eggs
Milk

  1. نسيان علامتي الاقتباس حول النص داخل console.log → خطأ SyntaxError.
  2. استخدام علامات اقتباس عربية أو ذكية بدل " " الإنجليزية → الكود لا يعمل.
  3. كتابة ملاحظة بالعربية أو الإنجليزية العادية داخل البرنامج بدون // → يعتبرها الحاسوب كودًا ويعطي خطأ.

الحسابات والنصوص

التصنيف: دسم (العمليات الحسابية الأربع + المعاملات + ربط النصوص بالصيغ)

1. الفكرة الأساسية

console.log لا يعرض النصوص فقط، بل ينفّذ العمليات الحسابية ويعرض ناتجها. وفي هذا الفصل نتعلّم ربط النص مع الصيغة الحسابية في سطر واحد.

2. المفاهيم الجديدة

أ) الفرق الجوهري: مع " " وبدونها

console.log("1+1");
console.log(1+1);
console.log(1400+3600);
Console ▸
1+1
2
5000

القاعدة: النصوص والجمل تُحاط بـ " "، أما الأرقام والصيغ الحسابية فلا.

ب) العمليات الحسابية الأربع والمعاملات

// "5x9" is written as "5*9"!
console.log(5*9)
// "10÷2" is written as "10/2"!
console.log(10/2)
Console ▸
45
5

الحاسوب يتعامل مع الأرقام الضخمة بسهولة، مثل console.log(10000000000*10000000000).

ج) ربط النص بالصيغة الحسابية (التجميع)

بدل كتابة كل جزء في سطر مستقل:

console.log("Set of 2 coffees " + (250 * 2) + " codycoins");
Console ▸
Set of 2 coffees 500 codycoins

القاعدتان المهمتان:

  • نربط الأجزاء بعلامة +.
  • الصيغة الحسابية تُحاط بأقواس ( ).
  • المسافة داخل النص ("Set of 2 coffees ") هي ما يفصل الكلمات عن الرقم.

مثال آخر نفّذته فعليًا:

console.log("Two muffins " + (320 * 2) + " codycoins");
Console ▸
Two muffins 640 codycoins

د) ربط نص بنص، ونص برقم

console.log("Today's recommendation is " + "soup.");
console.log("Limited to " + 30 + " servings.");
Console ▸
Today's recommendation is soup.
Limited to 30 servings.

المتغيرات

التصنيف: متوسط (درسان، مفهوم جديد واحد كبير: المتغيّر وما يتبعه)

1. الفكرة الأساسية

المتغيّر صندوق نضع فيه قيمة ونعطيه اسمًا، فنستطيع تغيير محتواه واستخدامه في أي مكان في البرنامج.

2. المفاهيم الجديدة

أ) الإعلان والإسناد

let fish;
fish = 0;
  • let fish; = إعلان متغيّر اسمه fish.
  • fish = 0; = إسناد القيمة 0 إليه.
  • اسم المتغيّر نختاره بأنفسنا، ويُفضَّل أن يعبّر عن محتواه.

ب) إعادة الإسناد

let fish;
fish = 0;
fish = fish + 3;
fish = fish + 7;
console.log(fish);
Console ▸
10

fish = fish + 3; تُقرأ: «خذ قيمة fish الحالية، أضف إليها 3، وأعد النتيجة إلى fish».

ج) عرض قيمة المتغيّر مقابل عرض اسمه كنص

console.log(fish);   // يعرض القيمة: 10
console.log("fish"); // يعرض النص: fish

علامات الاقتباس حول اسم المتغيّر تحوّله إلى نص.

د) قيمة ابتدائية غير الصفر

let allowance;
allowance = 700;
allowance = allowance + 1500;
console.log(allowance);
Console ▸
2200
ملاحظةملاحظة على صياغة غامضة في المنصة: نص التمرين يقول «3. أسند 1500 إلى allowance». ظاهر الصياغة يعني إسنادًا مباشرًا allowance = 1500; وتكون النتيجة 1500. لكن سياق الدرس (استلام مصروف يُضاف إلى ما في المحفظة) ولوحة «مثال: النتيجة» في المنصة يقصدان الإضافة allowance = allowance + 1500; وتكون النتيجة 2200، وهذه هي الإجابة التي تقبلها المنصة. يُستحسن تنبيه الطلاب للفرق بين «أسند القيمة» و«أضف القيمة».

4. أشهر الأخطاء

  1. كتابة console.log("fish") عند الرغبة في عرض القيمة → يعرض الكلمة بدل الرقم.
  2. نسيان let عند الإعلان أو تكرار let مع كل إسناد.
  3. الخلط بين «أسند» و«أضف»: x = 5; تستبدل القيمة، بينما x = x + 5; تضيف إليها.

5. اختبار المراجعة (من المنصة)

  • نطاق الأسئلة: Variables
  • عدد الأسئلة: 6

جملة if

التصنيف: دسم (اختصار الإعلان + التفرّع الشرطي + == مقابل = + true/false)

1. الفكرة الأساسية

جملة if تجعل البرنامج يتخذ قرارًا: ينفّذ أمرًا معيّنًا فقط إذا تحقّق شرط. والشرط نفسه قيمة منطقية ناتجها true أو false.

2. المفاهيم الجديدة

أ) اختصار الإعلان والإسناد في سطر واحد

let fish = 0;
fish = fish + 5;
console.log(fish);
Console ▸
5

بدل سطرين (let fish; ثم fish = 0;) نكتب let variable = value;. الاختصار يصحّ فقط مع أول إسناد؛ إعادة الإسناد تبقى كالمعتاد بدون let.

ب) جملة if

let science = 100;
if (science == 100){console.log("Increased allowance!");}
Console ▸
Increased allowance!

التركيب: if (الشرط) { المعالجة }

  • العبارة الشرطية داخل القوسين ( ).
  • المعالجة داخل القوسين المعقوفين { } (curly brackets).

إذا كانت القيمة 80 بدل 100، لا يتحقق الشرط ولا يُطبع شيء إطلاقًا (وحدة التحكم تبقى فارغة).

ج) الفرق بين = و ==

  • = علامة واحدة → إسناد قيمة إلى متغيّر.
  • == علامتان → مقارنة هل القيمتان متساويتان.

هذا من أكثر مواضع الخلط عند المبتدئين.

د) العبارة الشرطية تنتج true أو false

الشرط يمكن استخدامه وحده بدون if:

let science = 100;
console.log(science == 100);
Console ▸
true
let science = 80;
console.log(science == 100);
Console ▸
false

أي أن if ببساطة تنفّذ المعالجة عندما تكون قيمة الشرط true.

هـ) مثال تدريبي كامل

let math = 100;
if (math == 100){console.log("Get a reward");}
Console ▸
Get a reward

  2. نسيان الأقواس المعقوفة { } حول المعالجة، أو نسيان ; داخلها.
  3. توقّع ظهور شيء عندما يكون الشرط false — الصحيح أن وحدة التحكم تبقى فارغة تمامًا لأن لا بديل (else) بعد.
