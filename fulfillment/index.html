أين تجد كل ملاحظة؟

  1. بانر يشرح مستودعات سلة ← تصفح المستودعات
  2. كارد المستودع: صورة، مدينة، اسم المستودع، الخدمات، السعر، الأزرار ← تصفح المستودعات
  3. إعدادات المستودع بعد الحجز: نطاق التغطية وتسعيرة (عادي، سريع، اقتصادي) ← إعدادات مستودعات النخبة (درج أو صفحة)
  4. مستودعاتي كجدول، وقائمة ⋯ فيها الإعدادات وحذف المستودع ← مستودعاتي
  5. تعليمات المستودع ومنتجات تحتاج معاملة خاصة ← صفحة نقل المخزون، وأخطاء المنتجات المخالفة ← طلب نقل جديد
  6. حالات نقل المخزون: بانتظار التأكيد، نتيجة المراجعة، بعد فحص الجودة ← صفحة نقل المخزون (بدّل الحالة من الشريط الأصفر)
